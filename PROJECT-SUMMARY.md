## 🔧 Troubleshooting

If workflows don't appear:
1. Verify files are in `.github/workflows/`
2. Check YAML syntax is valid
3. Ensure GitHub Actions is enabled

If workflows fail:
1. Read error messages in Actions tab
2. Enable debug logging (see QUICKSTART.md)
3. Check comments in workflow file
